A simple, responsive, and lightweight **online metronome** built with **Next.js and React**.

> Designed as a hands-on project to explore **timing accuracy**, **audio handling in the browser**, and **modern frontend architecture**.

---

## 🌐 Live Demo

👉 https://isaacortga-slowmetronome.netlify.app/

---

## 🚀 Features

- 🎚 Adjustable BPM (40–300)
- ▶️ Start / Stop controls
- 🎼 4/4 time signature
- 🔊 Accented first beat
- 📱 Fully responsive UI (Tailwind CSS)

---

## 🛠 Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS

---

## 📦 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

### 4. Open in browser

```
http://localhost:3000
```

---

## 📁 Project Structure

```
src/
  app/                # App Router pages
  components/         # UI components
  hooks/              # Custom hooks (metronome logic)
  lib/                # Utilities and audio logic
```

---

## ⚙️ Current Limitations

- Uses basic audio playback (not sample-accurate)
- Fixed time signature (4/4)
- No subdivision support yet
